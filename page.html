ESTRUTURA

É neccesário ter uma estrutura semântica e organizada para o código fazer sentido para o SEO e não afetar a experiência do usuário, para isso temos tags html estruturais importantes sendo elas:

!DOCTYPE html

É o inicio do seu arquivo html, ela quem diz ao navegador o tipo de arquivo que ele irá ler.

html lang="pt-br"

É onde você indica ao navegador qual a lingua do seu projeto, no meu caso, português do Brasil pt-br, essa tag tem fechamento e fica no fim do seu código html.

head

Se HTML é o esqueleto do seu site, head é a cabeça desse esqueleto, nele vai conter boa parte da configuração do seu site, como meta tags e title, nessa tag tudo que estiver dentro não deve aparecer como conteúdo da página para o usuário.

title

Importante para dar nome ao seu projeto.

body

É o corpo do seu site, todo conteúdo da página estará dentro desta tag.
